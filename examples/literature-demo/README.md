# Synthetic literature workflow demonstration

This example proves the file-producing vertical slice without claiming that fixtures are research evidence.
Run `node scripts/literature-demo.ts` from the package root. The command writes
`literature/evidence-matrix.csv` and appends an entry to `literature/search-log.md` here.
It refuses an existing matrix. Use a new output directory for each demonstration;
never delete real evidence to rerun the demo.

Every record is explicitly synthetic. Replace it with searches across multiple providers, direct source
inspection, and citation chaining before drawing a literature or novelty conclusion.
