# Novelty analysis

Novelty is a comparison supported by search evidence, not a conclusion from failed retrieval. Read the research question, search log, evidence matrix, paper notes, and current experiment design. If the closest work is not represented by primary-source evidence, return to `literature-review` first.

Update `docs/novelty.md` with:

- research question and candidate contribution;
- closest prior work and what is already established;
- unresolved gap and proposed scientific distinction;
- evidence for and against distinctiveness;
- closest recent, preprint, OpenReview, workshop, or unpublished competing work;
- likely reviewer objection;
- result that would make the contribution uninteresting;
- prior publication that would invalidate novelty;
- current confidence and unresolved search tasks.

Compare along question, setting, data, intervention/mechanism, evaluation, and claim. A new dataset, model name, or application domain is not automatically a scientific distinction. Search aliases and predecessor terminology, reverse citations, authors' later work, and sources that contradict the hoped-for gap.

Phrase the conclusion within the explored scope. Give a confidence level with reasons and a next-review trigger. Run again after material design changes and immediately before submission.
